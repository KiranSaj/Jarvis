Before you run it

  1. Laptop speakers on, at a normal listening volume. Not headphones — the whole point is letting the microphone hear the speakers.
  2. Quiet room. Nobody talking, no music. It takes about 20 seconds.
  3. Allow the microphone when Chrome asks.
  4. Then don't touch anything until it finishes. It will speak once, then play a burst of speech-like noise.

Double-talk

The test above measured JARVIS talking alone. Barge-in is the other case — you talking while he talks. Cancellers often suppress the whole channel during far-end speech rather than subtracting only the echo, and that would take the child's voice with it. This measures whether it does.

Talk continuously over him for the whole utterance — count out loud, read this paragraph, anything. Normal speaking volume, speakers on as before.

ERLE is echo return loss enhancement: how much quieter the cancelled stream is than the raw one, in decibels. Above 10 dB the canceller is doing real work on that source. Below 3 dB it is not touching it. The Web Audio row is the control — Web Audio certainly goes through Chrome's render path, so if it cancels and speechSynthesis does not, the difference is the answer.
